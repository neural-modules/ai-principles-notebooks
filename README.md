# Basic Principles of Artificial Intelligence: exercise notebooks

One notebook for each lesson of the Basic Principles of Artificial Intelligence course on the [Applied Data Science](https://www.youtube.com/@neuralmodules) YouTube channel
([full playlist](https://www.youtube.com/playlist?list=PLDyCOTShSfCk)). Each notebook goes through its lesson step by step, with short explanations,
worked code, plots and exercises. Running an exercise cell checks your answer straight away, and hints are there
when you get stuck.

## How to use a notebook

1. Click **Open in Colab** next to the lesson.
2. Choose **File > Save a copy in Drive**, so your work is saved to your own account.
3. Run the set-up cell, then work down the page in order. Later exercises reuse earlier answers.

Nothing needs installing. Each notebook runs on Colab's free CPU in a few minutes.
